# Triage Labels

技能使用以下五种角色，通过本表映射到 GitHub 标签。

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求明确，可以交给 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到 triage 角色时，使用对应标签。日后可直接修改第二列以适配既有标签。

本文件仅声明映射，不表示这些标签已在 GitHub 上创建，也不表示已给任何 Issue 打标签。
